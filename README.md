# ☸️ Kubernetes Learning Repository

This repository contains my **daily Kubernetes learning, practice, notes, commands, and hands-on experiments**.

I am using this repository to document my Kubernetes journey step by step, from the fundamentals to more advanced  concepts.

---

## 🎯 Learning Goals

* Understand Kubernetes fundamentals
* Learn Kubernetes architecture and core components
* Deploy and manage applications on Kubernetes
* Work with Pods, Deployments, Services, and Namespaces
* Understand ConfigMaps and Secrets
* Learn Storage concepts such as PV and PVC
* Work with StatefulSets and DaemonSets
* Understand Kubernetes networking
* Learn Ingress and Ingress Controllers
* Work with Helm
* Learn Kubernetes security and RBAC
* Monitor Kubernetes workloads
* Practice troubleshooting and debugging
* Build and deploy real-world applications on Kubernetes
